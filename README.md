# Linden

Linden is a private, owner-operated assistant for documents, email and calendar tasks.

This repository contains only the public description, privacy policy and terms for its Google connection. It is not the assistant's source code, a server deployment package or a public hosted service.

- [Description](https://ars4tumblr-cmd.github.io/linden-access/)
- [Privacy policy](https://ars4tumblr-cmd.github.io/linden-access/privacy.html)
- [Terms of use](https://ars4tumblr-cmd.github.io/linden-access/terms.html)
- [Contact form](https://ars4tumblr-cmd.github.io/linden-access/contact.html)

Google access requires the account owner's authorization. Each specific outgoing email, deletion, sharing change and calendar mutation requires owner confirmation under the assistant's operating policy.

No credentials, server addresses, private files or deployment state belong in this repository.
